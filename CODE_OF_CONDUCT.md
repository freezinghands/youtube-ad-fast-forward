# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Be kind, assume good faith, and keep discussions about the work.

The maintainer, [@freezinghands](https://github.com/freezinghands), enforces it and may hide, edit or remove comments, issues and pull requests that break it, and block people who keep breaking it.

To report behaviour privately, email the maintainer at jy021316@gmail.com. You can also use GitHub's **Report content** on the comment or issue; that report goes to GitHub's staff.
