# Security policy

Please report a vulnerability privately: on the repository's **Security** tab, choose **Report a vulnerability**. Do not open a public issue for it.

Only the latest release is supported.

The extension has no permissions beyond running on `www.youtube.com`, makes no network requests and stores nothing. A report is most useful if it shows how a web page or another extension could use this extension to do something it should not, such as keep a tab muted or change a page outside YouTube.
